The primary files contain the POJ statement sample. The official files contain all 2,500 Tokyo 2009 problem G judge cases and answers, downloaded from https://storage.googleapis.com/files.icpc.jp/regional2009/InputsAndOutputs/G.in and https://storage.googleapis.com/files.icpc.jp/regional2009/InputsAndOutputs/G.ans on 2026-10-21. Answers are compared numerically with absolute tolerance 0.0001; the maximum observed difference was 0.000005.
