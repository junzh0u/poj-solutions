2322.in and 2322.out preserve the POJ sample. 2322-official.in and 2322-official.out come from the original Rocky Mountain 2003 contest package, https://org.coloradomesa.edu/~wmacevoy/rmrc/2003/problems.tgz, under problems/planks/cases/test1/. Contest program banners were removed from the expected output and line endings normalized. Output paths are witnesses; other valid placements are allowed.
