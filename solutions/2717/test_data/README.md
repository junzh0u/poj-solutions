The primary files are the POJ statement sample. Outputs are witnesses; equally short valid schedules may differ.

The official input combines test1 through test6 (116 instances) from the [2005 Rocky Mountain contest archive](https://org.coloradomesa.edu/~wmacevoy/rmrc/2005/problems.zip), paths `problems/hourglass/cases/test*/hourglass.in`. The published archive contains no output for this special-judge problem. `2717-official.out` contains schedules generated by the accepted solution and independently simulated for legal flips and expiration at the target.
