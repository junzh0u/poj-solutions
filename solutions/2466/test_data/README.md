The primary files contain the statement sample, also Waterloo data set B.1. The additional official sets come from https://icpc.student.cs.uwaterloo.ca/~acm00/010929/data/B.2.dat and B.3.dat, with expected outputs from the corresponding .diff files. Retrieved 2026-10-18. Outputs were checked for feasibility and every emitted witness was checked by reconstructing the complete multiset of pair sums; alternative valid witnesses are allowed.
