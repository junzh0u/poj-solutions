# 3560 — Supersquare

The special-judge gate was explicitly lifted for this run. The prior note recorded no attempts. Five fresh submissions by gpt-6-astra all received Time Limit Exceeded. Suggested park: model, because a judge failure is plausible but the evidence is insufficient to establish it.

The statement requires a 2n-digit square with both n-digit halves square, where the lower half may have leading zeroes but must be positive. It specifies T <= 10 and 1 <= n <= 500, 1000 MS and 65536 K. Every allowed n has a construction; no impossible answer is needed.

For n >= 2, let M=10^n, q=M/4, and a=floor(sqrt(q)), reducing a by one when n is even and the root is exact. Put t=q-a^2 and c=q+a^2. Then c^2=a^2*M+t^2, and 0<t<sqrt(M). The first half a^2 has exactly n digits: check n=2 directly (a=4), and for n>=3 the bound a>sqrt(M)/2-1 implies a^2>=M/10. The second half is t^2, positive and below M. For n=1 output 49. This reproduces the official sample exactly: n=1 gives 49 and n=2 gives 1681.

The initial implementation computed an integer square root by decimal digit extraction and squared decimal strings. The optimized implementation used a certified decimal prefix of sqrt(2.5): for odd n=2k+1, a is its first k+1 digits. Even n uses 4 followed by n/2-1 nines. Base-10000 multiplication removed the runtime square root and reduced the multiplication constant. An independent fixed-array decimal implementation then removed all string, vector and iostream operations. All versions were checked for every n from 1 through 500 using Python's exact math.isqrt on the complete output and each half, as well as length and positivity assertions. Tests were grouped in legal batches of ten. The complete 500-case run, including fifty process launches, took 0.124 seconds for the base-10000 version and 0.137 seconds for the fixed-array version on the local machine. The oracle accepted the sample and rejected deliberate zero-suffix and nonsquare mutations. No local disagreement was found.
