## Reading and algorithm

The statement describes a DAG of extracts, assumptions, and theories. Extracts are inherently true. An assumption is plausible if at least one predecessor chooses its explanation leading to that assumption. A theory requires every predecessor to be plausible and to choose its explanation leading to that theory. Each extract or assumption can choose at most one outgoing explanation because explanations are exclusive. Theory values are distinct powers of two up to 2^(K-1), with K up to 100, so decimal strings were used for exact values.

Under that reading, every needed immediate predecessor of a theory must be reached from an extract by a vertex-disjoint directed path. Unit capacity on extracts and assumptions enforces exclusive outgoing explanations. Incoming flow to an assumption supplies the one justification it needs; unnecessary additional justifications can be discarded. A theory's sink capacity equals its indegree. Saturating that capacity forces every immediate predecessor to support the theory, since each incoming explanation edge has capacity one and each predecessor has unit vertex capacity.

Construct the network with in/out vertices for each extract and assumption, capacity-one, zero-cost in-to-out edges, source-to-extract-in capacity one, and every original explanation represented by out-to-target-in capacity one and cost one. Theory vertices have no out vertex or outgoing explanation. Process theories in decreasing numeric value. For a candidate, copy the current residual network, add theory-to-sink capacity equal to indegree, and attempt to send that many additional units with Dinic. If successful, retain the copied network and mark the theory selected; otherwise discard the copy. Disable the reverse residual capacity of each accepted theory-to-sink edge so future augmentation cannot cancel the established demand. All other residual edges remain available to reroute prior paths. This lexicographic greedy should maximize the sum because each power of two exceeds the sum of all lower powers.

Finally rebuild the zero-flow network, add sink edges for the selected theories, and run successive shortest augmenting paths using SPFA and the explanation-edge costs. The total cost is the minimum explanation count. Decimal-string addition computes the chosen total value. Parse descriptions with token extraction: after every extract/assumption read the separating '-' token, and after each theory except the final one read its '-'. Read cases until 0 0 0.

The intended output is `Case c:` on its own line, total decimal value, minimum explanation count, then each selected theory name on a separate line, with one blank line between cases. POJ's HTML and the original contest PDF both omit a name-order rule. The original PDF, mirrored from Live Archive 3697 through VJudge, was checked and has the same wording and sample as POJ.
