# 2430 Lazy Cows

One submission, one Wrong Answer, run stopped by the user with four attempts unspent. The distinguishing feature of this park: the solution passed an unusually deep local verification battery and still drew WA, and an extended post-verdict hunt found no bug — so either the verification shares a misreading with the solution, or the model of the problem is subtly wrong in a way two brute forces also shared.

## The reading and the algorithm

Cows occupy cells of a 2-row by B-column grid (N cows, coordinates up to B = 15,000,000, N and K up to 1000). Choose at most K axis-aligned rectangular barns covering every cow, minimizing total barn area. Solution: coordinate-compress occupied columns, then a 5-state DP per compressed column — nothing open / row-A-only barn open / row-B-only open / both rows open as separate barns / one merged height-2 barn open — tracking the barns-used budget against K, charging area per column span as barns extend.
