# 1726 — Tango Tango Insurrection

The special-judge gate was explicitly lifted for this run. Suggested classification: judge. Two submissions failed, including the original contest's independent reference solution; no algorithmic counterexample was found.

The state is the time index, both foot positions, and the foot active at the previous time (left, right, or neither). Every required arrow is tapped by exactly one foot. On a period, either rest or move/tap one foot; resting clears the previous-foot state. A foot under a crossover may tap its current arrow but cannot change arrows until the crossed foot moves away. Both feet must remain distinct and the simultaneously swapped Left/Right position is forbidden. Repeated-foot costs are 3, 5, or 7 according to distance; all other actions cost 1. Backward dynamic programming and reconstruction take O(n * 4 * 4 * 3 * 8) time and O(n * 4 * 4 * 3) memory. The initial feet are Left and Right, with neither previously active.

// POJ 1726 - Tango Tango Insurrection
// Model: gpt-6-astra
// Dynamic programming over time, both foot positions and the last active foot.
// A rest resets the last foot; a dot may also be used to reposition a foot.
// A crossed foot locks the other foot's position, but does not forbid tapping.
#include <iostream>
#include <string>
#include <cstring>
using namespace std;
int dp[80][4][4][3], choice[80][4][4][3];
const char *arrows="ULDR";
int main() {
    string s;
    while (cin>>s && s!="#") {
        int n=s.size();
        memset(dp,0,sizeof(dp));
        for(int i=n-1;i>=0;--i) for(int l=0;l<4;++l)
        for(int r=0;r<4;++r) for(int last=0;last<3;++last) {
            int &best=dp[i][l][r][last];
            int &take=choice[i][l][r][last];
            best=100000; take=-1;
            if(s[i]=='.') {best=dp[i+1][l][r][2]; take=8;}
            for(int foot=0;foot<2;++foot) for(int to=0;to<4;++to) {
                if(s[i]!='.' && arrows[to]!=s[i]) continue;
                int nl=foot==0?to:l, nr=foot==1?to:r;
                if(nl==nr || (nl==3 && nr==1)) continue;
                if(foot==0 && r==1 && nl!=l) continue;
                if(foot==1 && l==3 && nr!=r) continue;
                int old=foot==0?l:r;
                int cost=last!=foot?1:(old==to?3:((old^to)==2?7:5));
                cost+=dp[i+1][nl][nr][foot];
                if(cost<best) {best=cost;take=foot*4+to;}
            }
        }
        int l=1,r=3,last=2;
        for(int i=0;i<n;++i) {
            int c=choice[i][l][r][last];
            if(c==8) {cout<<'.';last=2;}
            else if(c<4) {cout<<'L';l=c;last=0;}
            else {cout<<'R';r=c-4;last=1;}
        }
        cout<<'\n';
    }
    return 0;
}
