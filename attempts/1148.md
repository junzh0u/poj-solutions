# 1148 — Utopia Divided

Suggested park: judge. The special-judge policy gate was explicitly lifted for this run. Two independently implemented, locally verified solutions both received System Error; this verdict gives no evidence of a program defect. Resume only after public submissions demonstrate judge recovery.

The input gives 2N distinct positive lengths and N destination quadrants, N <= 10000. Every length must occur once in the signed displacement pairs, and every cumulative position must be strictly inside the requested quadrant. The two coordinates can be constructed independently after splitting the sorted lengths into halves.

For each sorted half, alternate the signs so its largest entry has the sign of the final coordinate. Any nonempty contiguous interval has a strictly nonzero sum with the sign of its largest-magnitude member: pairing successive opposite signs proves this directly. Count the equal-sign transitions in the requested coordinate sequence and begin at that index. For an equal-sign transition extend the used interval left; for a sign change extend it right. The count guarantees exactly enough room on each side. The initial sign is correct because the number of right extensions is the number of sign changes. This constructs a solution for every valid input in O(N log N) time and O(N) memory, without needing a no-solution branch. Code values fit 32 bits, and cumulative coordinate magnitude is at most the largest code in its half.

## Original submitted source

```cpp
// POJ 1148 - Utopia Divided
// Model: gpt-6-astra
// Sort and split the codes between the two axes. Give each sorted half
// alternating signs, ending with the sign of the final destination.
// A contiguous interval has a nonzero sum with its largest term's sign.
// Extend left to preserve that sign and right to reverse it. Start at
// the number of equal-sign transitions, so neither endpoint runs out.
// Thus every valid input has a solution. Complexity: O(N log N), O(N).
#include <cstdio>
#include <algorithm>
using namespace std;
int codes[20000], region[10000], answer[10000][2];
int signAt(int r, int axis) {
    return axis == 0 ? ((r == 1 || r == 4) ? 1 : -1)
                     : (r <= 2 ? 1 : -1);
}
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < 2*n; ++i) scanf("%d", &codes[i]);
    for (int i = 0; i < n; ++i) scanf("%d", &region[i]);
    sort(codes, codes + 2*n);
    for (int axis = 0; axis < 2; ++axis) {
        int *a = codes + axis*n;
        int s = signAt(region[n-1], axis);
        for (int i = n-1; i >= 0; --i, s = -s) a[i] *= s;
        int start = 0;
        for (int i = 1; i < n; ++i)
            if (signAt(region[i], axis) == signAt(region[i-1], axis)) ++start;
        int left = start, right = start;
        answer[0][axis] = a[start];
        for (int i = 1; i < n; ++i) {
            if (signAt(region[i], axis) == signAt(region[i-1], axis))
                answer[i][axis] = a[--left];
            else answer[i][axis] = a[++right];
        }
    }
    for (int i = 0; i < n; ++i) printf("%+d %+d\n", answer[i][0], answer[i][1]);
    return 0;
}
```
