The input is a single case. There are n missile launches (1 <= n <= 50000), each given as p, x, y with 0 <= p < x <= 50000 and 1 <= y <= 50. Launches occur at integer times 1 through n. The missile parabola is h(q) = y * (1 - ((q-x)/(x-p))^2), clipped below at zero. Then m (1 <= m <= 20000) queries give inclusive launch-index bounds t1,t2 and inclusive spatial bounds x1,x2, all spatial coordinates integral in [0,50000]. Output the maximum missile height over those two intervals, zero if no positive trajectory intersects. The original checker permits absolute error 1e-4. POJ advertises 1000 ms and 65536 KB; the original contest mirror has substantially larger resource limits.

The first implementation used a segment tree over launch indices. Each node stored the pointwise upper envelope of its parabolas at integer coordinates, compressed into runs of the winning missile. Child envelopes were merged by walking overlapping runs, splitting the difference quadratic at its vertex, and binary searching a sign change on each monotone half. Each envelope had a range-maximum tree over runs, and partial runs were evaluated at their clamped peak. This integer-coordinate restriction is exact: every contributing parabola's peak and every query endpoint are integers, so a maximum over any query interval occurs at an integer coordinate. Stable vertex-form evaluation avoids cancellation near narrow peaks. Range maxima were stored as float, whose absolute rounding error below height 50 is far below 1e-4; boundary evaluations used double.
