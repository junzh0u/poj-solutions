# 1903 Jurassic Remains

The special-judge gate was explicitly lifted for this gpt-6-astra run. Suggest a judge park: an independently designed exact solution and a translated original contest jury solution both receive Wrong Answer, with successful local optimality and witness checks. The visible unrelated-user evidence comprises only one other account, so this is strong control evidence rather than broad independent-user coverage.

## Statement and solution

There are at most 24 bones. Each has a nonempty set of distinct labels A through Z. Select as many bones as possible so that every labeled joint can be paired with a joint on another selected bone bearing the same label. Separate fragments and multiple connections between two bones are allowed. This is equivalent to each label appearing an even number of times. Sufficiency follows by pairing the occurrences of each label arbitrarily: no bone contains that label twice, so each pair necessarily joins distinct bones.

Encode each bone as a 26-bit mask. Enumerate all subsets of the first half, storing for every XOR mask the subset with greatest cardinality. Enumerate the second half and match equal XOR masks. Maximize the combined cardinality, then emit the selected indices in ascending order. The empty set is valid. This uses O(N * 2^(N/2)) time and O(2^(N/2)) space; all masks and counts fit signed 32-bit integers.

## Verification and independent evidence

The official sample reproduced byte-for-byte: five bones, indices 1 2 3 5 6. A brute force counted actual occurrences of each label, rather than sharing the meet-in-the-middle implementation. It verified all 399 ordered inputs of one to three bones over the seven nonempty subsets of ABC, plus 250 seeded random inputs of up to twelve bones. Witness checks required exactly the printed number of distinct, ascending, in-range indices and even occurrence counts for every label. Maximum-size tests included 24 independent single-letter bones (answer zero) and 24 identical full-alphabet bones (answer 24). Deliberately retaining the smallest first-half subset for each mask was rejected by the sample.

The original NEERC 2003 jury archive is publicly available at https://neerc.ifmo.ru/archive/2003/archive.rar, linked from https://neerc.ifmo.ru/archive/2003.html. Its archive/solutions/jurassic/checkj.dpr checks exactly ascending distinct bone indices, parity for each label, and cardinality against the jury answer. The supplied tests/01 is the POJ sample, and tests/02 is one bone ABC, whose answer is zero. Most further tests are Pascal generators rather than stored inputs. The discussion at http://poj.org/bbs?problem_id=1903 independently mentions even label counts and XOR; no framing exception was found.

A C++98 translation of Roman Elizarov's archive/solutions/jurassic/j_re.java was submitted as an independent control. Only file I/O was replaced with standard input/output; the recursive search order and pruning were preserved. Both implementations agreed on the optimum for 50 seeded random instances with 24 bones and 26 labels, and every returned witness was checked. The control deliberately used G++ instead of the original submission's C++ compiler.

The complete control source is preserved below, including the exact model annotation:

```cpp
// POJ 1903 - Jurassic Remains
// Model: gpt-6-astra
// Control: C++98 translation of Roman Elizarov's NEERC 2003 jury
// solution j_re.java from https://neerc.ifmo.ru/archive/2003/archive.rar.
// Exhaustive subset recursion with a remaining-cardinality upper bound.
// A solution has an even count of every label; fragments may be separate.
#include <cstdio>
int best_bones, best_len, n, patterns[24];
void find(int joints, int bones, int len, int i) {
    if (joints == 0 && len > best_len) {
        best_bones = bones;
        best_len = len;
    }
    if (len + (n - i) <= best_len || i >= n) return;
    find(joints, bones, len, i + 1);
    find(joints ^ patterns[i], bones | (1 << i), len + 1, i + 1);
}
int main() {
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < n; ++i) {
        char s[30];
        scanf("%29s", s);
        for (int j = 0; s[j]; ++j) patterns[i] |= 1 << (s[j] - 'A');
    }
    find(0, 0, 0, 0);
    printf("%d\n", best_len);
    for (int i = 0; i < n; ++i)
        if ((best_bones & (1 << i)) != 0) printf("%d ", i + 1);
    printf("\n");
    return 0;
}
```
