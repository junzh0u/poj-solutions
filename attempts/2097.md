## Statement and algorithm

The input is a simple orthogonal polygon without holes, with alternating horizontal and vertical edges. Coordinates are integers in [-200,200]; the POJ statement says at most 400 vertices, while the original jury solution allows 800. Output a minimum-cardinality partition into nonoverlapping axis-aligned rectangles, giving each rectangle's minimum and maximum coordinates.

For R reflex corners, an optimum uses R+1-D rectangles, where D is the maximum number of mutually nonintersecting interior diagonals joining pairs of reflex corners. Horizontal diagonals conflict only with vertical diagonals, including shared endpoints. A maximum matching gives a minimum vertex cover and hence a maximum independent set. Install those diagonals, then extend each unpaired reflex corner horizontally until it reaches the polygon boundary or an installed vertical cut. Flood the resulting cells to produce the rectangles. Occupied unit cells make interior-diagonal detection and output construction exact, without floating point or orientation assumptions.

The first implementation reads a single polygon. One official jury program, drawing_gk.dpr, reads until EOF; the other, drawing_as.dpr, reads one polygon. The statement has no leading test count. The second submission tests EOF framing and resets every per-case structure. This did not resolve WA. No actual multi-case POJ input has been observed, so EOF framing remains a hypothesis rather than an established statement correction.
