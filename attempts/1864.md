# 1864 — Funny Card Game

The special-judge hold was lifted for this run. Two independently implemented canonical solutions received Wrong Answer. Suggested classification: judge, supported by the public status history and the independent control below. This is an evidence-based diagnosis rather than a proof about inaccessible judge data; the control was independently implemented from a published editorial, not copied from a historically Accepted submission.

## Rules and algorithm

Every card except the final one must force the opponent to skip: 6, 7, A, or KS. Hence two ordinary cards make the answer NO. A queen and an eight count as ordinary. There are at most thirteen distinct skip cards, two jokers, and one final ordinary card. Adjacent effective cards must share rank or suit; after a queen only its announced suit matches. A joker is assigned an actual rank and suit and still must match the preceding card; it cannot bridge arbitrary incompatible suits. Assigning a joker a skip card suffices even on the final move, because the current suit always has a legal six. A final queen needs an announced suit appended to its output, though that choice no longer affects the result.

The first solution memoizes failed states (remaining physical-card mask, effective top card), exploring matching skip-card assignments for each joker. The independent control instead removes the one ordinary card, performs bottom-up subset reachability over the remaining physical cards and thirteen effective top cards, and reconstructs a witness from predecessor states. It checks the final ordinary card only after all special cards have been used. Neither algorithm needs deck contents or the other player's hand.

## Independent evidence and verification

The original Timus problem is https://acm.timus.ru/problem.aspx?space=1&num=1166 . Its explicit note says a queen can cover a queen only in the announced suit. POJ discussion https://poj.org/showmessage?message_id=351255 reports the same clarification. Timus discussion https://acm.timus.ru/forum/thread.aspx?id=20921 confirms that only 6, 7, A, and KS can be intermediate cards and that a joker must match both neighboring cards.

The independent control follows Andrija Jovanovic's solution analysis on printed pages 64–65 of https://bubblecup.org/Content/Media/Booklet2011.pdf . The analysis derives the sixteen-card bound and subset dynamic programming. Its later references to eights are a typographical inconsistency: its preceding paragraph explicitly classifies eights as ordinary, and the statement and Timus clarification specify aces as skip cards. No original contest test package was recovered.

Both C++98 programs compiled with -pedantic -Wall -Wextra -O2. Each passed 500 deterministic randomized small instances against a separate exhaustive permutation search (random seed 1864), including joker assignments over all 52 possible cards, plus 52 maximal sixteen-card hands starting from every rank/suit. Every positive output was independently checked for exact hand multiplicities, legal adjacency, mandatory intermediate skip effects, and queen formatting. The control's 52 maximal-hand runs took about 1.03 seconds combined locally. These checks establish broad local agreement; they do not provide access to POJ's private input.

The official sample admits multiple valid sequences; the original produced `KS 7S 6S 6C *6D QDS`, which was validated as a complete legal witness. The queen mutant that allows equal queen ranks fails the separating case `QD` / `QHS`: the correct result is NO, but the mutant produces YES. Also checked: `8S 6S` / `2S` gives `YES 6S 8S`; `TS *` / `3S` has a winning sequence; `*` / `QCD` is solved with `*6D`. The last two cases were independently posted in https://acm.timus.ru/forum/thread.aspx?id=19874 .

## Original submitted source

```cpp
// POJ 1864 - Funny Card Game
// Model: gpt-6-astra
// Only 6, 7, A and KS can precede the final card. Search subsets of
// these cards and jokers, memoizing the remaining mask and top card.
// A queen requires its announced suit, even against another queen.
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
#include <cstring>
using namespace std;
string ranks="23456789TJQKA", suits="SCDH";
vector<int> cards, path;
vector<unsigned char> dead;
int n;
int id(string s) { return int(ranks.find(s[0]))*4+int(suits.find(s[1])); }
bool skip(int x) { return x/4==4 || x/4==5 || x/4==12 || x==44; }
bool match(int a,int b) { return a%4==b%4 || (b/4!=10 && a/4==b/4); }
bool dfs(int mask,int top) {
    if(!mask) return true;
    int key=mask*52+top;
    if(dead[key]) return false;
    for(int i=0;i<n;++i) if(mask&(1<<i)) {
        int rest=mask^(1<<i);
        if(cards[i]>=0) {
            int c=cards[i];
            if((!rest || skip(c)) && match(c,top)) {
                path.push_back(c);
                if(dfs(rest,c)) return true;
                path.pop_back();
            }
        } else {
            for(int c=0;c<52;++c) if(skip(c) && match(c,top)) {
                path.push_back(c+52);
                if(dfs(rest,c)) return true;
                path.pop_back();
            }
        }
    }
    dead[key]=1;
    return false;
}
int main() {
    string line,s; getline(cin,line); istringstream in(line);
    int ordinary=0;
    while(in>>s) { int c=s=="*"?-1:id(s); cards.push_back(c); if(c>=0&&!skip(c)) ++ordinary; }
    cin>>s; if(s[0]=='*') s=s.substr(1);
    int top=id(s); if(s[0]=='Q') top=40+int(suits.find(s[2]));
    n=int(cards.size());
    if(ordinary>1 || n>16) { cout<<"NO\n"; return 0; }
    dead.resize((1<<n)*52,0);
    if(!dfs((1<<n)-1,top)) { cout<<"NO\n"; return 0; }
    cout<<"YES\n";
    for(int i=0;i<n;++i) {
        if(i) cout<<' ';
        int c=path[i]; if(c>=52) { cout<<'*'; c-=52; }
        cout<<ranks[c/4]<<suits[c%4]; if(c/4==10) cout<<'S';
    }
    cout<<'\n';
}
```

## Independent control submitted source

// POJ 1864 - Funny Card Game
// Model: gpt-6-astra
// Independent bottom-up control following Andrija Jovanovic's analysis in
// the Bubble Cup 2011 booklet, pp. 64-65. Subset reachability retains
// every possible effective skip card; a single ordinary card goes last.
// Queens are covered only in their announced suit (Timus clarification).
#include <iostream>
#include <sstream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;
const char *names[]={"6S","6C","6D","6H","7S","7C","7D","7H","AS","AC","AD","AH","KS"};
bool fits(string a,string b) {
    if(b[0]=='Q') return a[1]==b[2];
    return a[0]==b[0] || a[1]==b[1];
}
int special(string s) { for(int i=0;i<13;++i) if(s==names[i]) return i; return -1; }
string printable(string s) { return s[0]=='Q'?s+"S":s; }
int main() {
    string line,x,top,last=""; getline(cin,line); istringstream in(line);
    vector<int> hand; int bad=0;
    while(in>>x) {
        if(x=="*") hand.push_back(-1);
        else if(special(x)>=0) hand.push_back(special(x));
        else {last=x;++bad;}
    }
    cin>>top; if(top[0]=='*') top=top.substr(1);
    if(bad>1) {cout<<"NO\n";return 0;}
    int n=hand.size(),full=(1<<n)-1;
    if(n==0) {
        if(last.empty()||fits(last,top)) cout<<"YES\n"<<printable(last)<<'\n';
        else cout<<"NO\n";
        return 0;
    }
    bool compatible[13][13];
    for(int c=0;c<13;++c) for(int d=0;d<13;++d) compatible[c][d]=fits(names[d],names[c]);
    vector<int> parent((1<<n)*13,-2);
    for(int i=0;i<n;++i) for(int c=0;c<13;++c)
        if((hand[i]<0||hand[i]==c)&&fits(names[c],top)) parent[(1<<i)*13+c]=-1;
    for(int m=1;m<=full;++m) for(int c=0;c<13;++c) if(parent[m*13+c]!=-2)
        for(int i=0;i<n;++i) if(!(m&(1<<i))) for(int d=0;d<13;++d)
            if((hand[i]<0||hand[i]==d)&&compatible[c][d]) {
                int next=(m|(1<<i))*13+d;
                if(parent[next]==-2) parent[next]=m*13+c;
            }
    int end=-1;
    for(int c=0;c<13;++c) if(parent[full*13+c]!=-2 && (last.empty()||fits(last,names[c]))) {end=full*13+c;break;}
    if(end<0) {cout<<"NO\n";return 0;}
    vector<string> answer;
    for(int state=end;state>=0;) {
        int p=parent[state], diff=(state/13)^(p<0?0:p/13),i=0;
        while(!(diff&(1<<i))) ++i;
        string s=names[state%13]; if(hand[i]<0) s="*"+s;
        answer.push_back(s);state=p;
    }
    reverse(answer.begin(),answer.end());if(!last.empty()) answer.push_back(printable(last));
    cout<<"YES\n";
    for(unsigned i=0;i<answer.size();++i) {if(i)cout<<' ';cout<<answer[i];}
    cout<<'\n';
}
