An unknown age lies in [1,n]. A query x <= n returns gcd(x,age). The optimal worst-case number of queries equals the minimum number of groups of primes up to n whose products are at most n. The age-one branch requires eliminating every prime. The official analysis at https://neerc.ifmo.ru/archive/2011/neerc-2011-analysis.pdf, slide 8, explicitly identifies one as hardest and prescribes greedy grouping. Sieve the primes, take the largest remaining prime, and multiply in the smallest remaining primes while the product stays within n. Count the resulting groups. Division guards avoid overflow; all arithmetic fits 32-bit integers.

```cpp
#include <cstdio>
#include <cassert>
const int maxN = 10000;
int n, pn, p[maxN + 1];
int main() {
  assert(scanf("%d", &n) == 1);
  assert(1 <= n && n <= maxN);
  for (int i = 2; i <= n; i++)
    if (!p[i]) {
      p[pn++] = i;
      for (int j = i + i; j <= n; j += i) p[j] = 1;
    }
  int i = 0, j = pn - 1, cnt = 0;
  while (i <= j) {
    int x = p[j--];
    if (i <= j && p[i] <= n / x) x *= p[i++];
    cnt++;
  }
  printf("%d\n", cnt);
  return 0;
}
```
