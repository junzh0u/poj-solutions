# 1902 — Illumination

Suggested classification: judge. Two independently constructed solutions receive Wrong Answer, including a published historical Accepted control. No local failing case was found. The gate was explicitly lifted for this run; the old front matter is retained for the parent to replace.

## Construction and proof

Each source must illuminate a closed cone of angle 2*pi/N, and the N cones must cover the whole plane. Input is one case, 3 <= N <= 30, distinct integer points with coordinates in [-100,100]. Output N bisector angles in radians in input order.

Choose the N unit vectors at angles 2*pi*j/N. Use a minimum-cost perfect assignment between sources p_i and these vectors v_j, with cost p_i dot v_j. Aim each source along its assigned vector. The normal cone of a vertex of this regular polygon has exactly the required angle. If a point q were outside every translated normal cone, for every assigned vertex v_i there would be another vertex v_j with (q-p_i) dot (v_j-v_i)>0. Direct each vertex toward one such vertex. A directed cycle exists. Summing the inequalities around that cycle cancels q and proves that cyclically reassigning its vertices strictly decreases the assignment cost, contradicting optimality. Thus every point is covered. Hungarian matching costs O(N^3); double precision with 15 output decimals suffices for the official checker's 1e-5 tolerance.

// POJ 1902 - Illumination
// Model: gpt-6-astra
// Assign the vertices of a regular N-gon to the sources, minimizing
// sum(dot(source, vertex)) by the Hungarian algorithm in O(N^3).
// Aim each light along its assigned vertex's direction (normal cone).
// If a point were unlit, each vertex could point to another vertex with
// larger dot(point-source, vertex). A directed cycle would then strictly
// decrease the assignment cost, a contradiction. Cone sides are included.
#include <cstdio>
#include <cmath>
#include <algorithm>
using namespace std;
int main() {
    int n;
    if (scanf("%d", &n)!=1) return 0;
    double c[31][31], angle[31], u[31]={0}, v[31]={0}, ans[31];
    int p[31]={0}, way[31]={0};
    const double pi=acos(-1.0);
    for(int j=1;j<=n;++j) angle[j]=2*pi*(j-1)/n;
    for(int i=1;i<=n;++i) {
        double x,y; scanf("%lf%lf",&x,&y);
        for(int j=1;j<=n;++j) c[i][j]=x*cos(angle[j])+y*sin(angle[j]);
    }
    for(int i=1;i<=n;++i) {
        p[0]=i;
        int j0=0;
        double best[31]; bool used[31]={false};
        for(int j=1;j<=n;++j) best[j]=1e100;
        do {
            used[j0]=true;
            int i0=p[j0], j1=0;
            double delta=1e100;
            for(int j=1;j<=n;++j) if(!used[j]) {
                double cur=c[i0][j]-u[i0]-v[j];
                if(cur<best[j]) {best[j]=cur; way[j]=j0;}
                if(best[j]<delta) {delta=best[j];j1=j;}
            }
            for(int j=0;j<=n;++j)
                if(used[j]) {u[p[j]]+=delta;v[j]-=delta;}
                else best[j]-=delta;
            j0=j1;
        } while(p[j0]!=0);
        do {int j1=way[j0];p[j0]=p[j1];j0=j1;} while(j0);
    }
    for(int j=1;j<=n;++j) ans[p[j]]=angle[j];
    for(int i=1;i<=n;++i) printf("%.15f\n",ans[i]);
    return 0;
}
