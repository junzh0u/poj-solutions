# 3430 — Pizza schedule

The 2026-10-18 gpt-6-astra run lifted the special-judge gate. The prior gate record had no solver attempts. Five C++ language-4 submissions were made, all without acceptance.

For a candidate period L in 1..4, assign each calendar day to (day - start-of-earliest-week) modulo 7L. Only days from the earliest recorded delivery through the latest recorded delivery are scored. Fill absent delivery records within that interval with zero. Each residue class independently chooses a modal quantity; the sum of modal frequencies is the maximum number of matching days for that period. Choose the period with the largest sum. This is an exact separable optimization, uses a 28 by 101 frequency table, and needs far less than the 1000 ms / 65536 KB limits. Input records may be unordered; minimum and maximum day are computed explicitly. The input is one dataset with an explicit record count.

```cpp
// POJ 3430 - Pizza schedule
// Model: gpt-6-astra
// For each possible period, choose a most frequent quantity in every day
// class. Only the interval from first through last delivery is scored;
// missing deliveries inside it have quantity zero. Anchor at the first week.
// Resolve ties with the shortest period and the smallest quantity.
#include <cstdio>
#include <cstring>
#include <algorithm>
using namespace std;
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    int a[364] = {0}, lo = 364, hi = -1;
    for (int i = 0; i < n; ++i) {
        int w,d,q; scanf("%d%d%d", &w,&d,&q);
        int t = (w-1)*7+d-1;
        a[t] = q; lo = min(lo,t); hi = max(hi,t);
    }
    int base = lo/7*7, best = -1, length = 1, answer[28] = {0};
    for (int l = 1; l <= 4; ++l) {
        int freq[28][101]; memset(freq,0,sizeof(freq));
        for (int t = lo; t <= hi; ++t) ++freq[(t-base)%(7*l)][a[t]];
        int score = 0, value[28];
        for (int r = 0; r < 7*l; ++r) {
            int count = -1; value[r] = 0;
            for (int q = 0; q <= 100; ++q)
                if (freq[r][q] > count) { count = freq[r][q]; value[r] = q; }
            if (count == 0) value[r] = 0;
            score += count;
        }
        if (score > best) {
            best = score; length = l;
            for (int r = 0; r < 7*l; ++r) answer[r] = value[r];
        }
    }
    printf("%d ",length);
    for (int r = 0; r < 7*length; ++r) printf("%d%c",answer[r],r==7*length-1?'\n':' ');
    return 0;
}
```
