# 1238 — Arbitrage

Recommend a judge park: both a locally verified exact-length max-product solver and an independently authored historical control receive Wrong Answer. The task explicitly lifted the former special-judge gate for this run.

For each conversion table, find a closed exchange walk with product strictly greater than 1.01, using the fewest exchanges and at most n exchanges. Tables run to EOF, omit diagonal entries, and have n at most 20. Repeated currencies are permitted. The solution keeps the maximum product for each start, end, and exact exchange count, appends one rate per transition, and stops at the first layer with a profitable diagonal. Predecessors reconstruct the full closed walk. Complexity is O(n^4) time and O(n^3) storage. The output preserves the sample's leading space on sequence lines.

The original source matched the sample byte for byte. A deterministic set of 603 small cases was checked against complete enumeration of closed walks for every candidate length; checks validated minimal length, indices, closure, and actual product of the emitted sequence. Cases included exactly 1.01, 1.0101, and 1.005 products. The 1.005 case separates the erroneous positive-profit threshold from the required one-percent threshold, which the sample does not distinguish. One hundred n=20 all-unit-rate tables tested the full negative path. No disagreement was found. Searching for the original Duke 1990 contest data did not locate a usable archive.
