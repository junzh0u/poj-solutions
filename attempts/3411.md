# 3411 Paid Roads — not accepted

## The problem

Find the cheapest directed route from city 1 to city N. Each road `(a, b, c, P, R)` costs `P` if city `c` has already been visited and `R` otherwise, so the route state must remember both the current city and the set of visited cities. Revisiting cities is allowed and can unlock cheaper later edges.

## The solution

Run Dijkstra over `(visited-city mask, current city)`. When traversing a road, choose its cost from whether `c` is set in the current mask, then add `b` to the mask. The answer is the minimum finalized distance whose current city is N; unreachable inputs print `impossible`.

The implementation was tested under C++98 against the sample, `N=1`, cheap and expensive payment branches, revisit-to-unlock paths, unreachable graphs, discussion-board cases with answers 13 and 67, concatenated datasets, and 300 randomized comparisons with an independently derived state-graph reference.
