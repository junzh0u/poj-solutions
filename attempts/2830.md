## Interpretation and algorithm

For every input case, maximize the product of a nonempty contiguous subsequence. Input runs to EOF; N is at most 100000 and factors have at most one decimal place, with absolute values at most 30. Empty products are not candidates. Keep both the minimum and maximum products ending at each position: the new extrema are selected from the current element and its products with both previous extrema. The maximum of all suffix maxima is the answer. Zero participates normally, and a lone negative must remain negative.

Represent each product with its sign, a long-double mantissa in [1,10), and an integer decimal exponent. Each multiplication normalizes only small bounded mantissas, avoiding overflow even for 100000 factors of 30. Comparisons use sign first, then exponent and mantissa with the order reversed for negatives. This takes O(N) time and O(1) auxiliary memory.

Output uses three fractional digits in the normalized mantissa. Rounding a mantissa to 10 carries one into the exponent. After carrying, exponent zero is omitted. The problem discussion explicitly warns against output such as 10.000E5 (message 48416). Messages 130030 and 143025 provide the separating input below and expected 1.000E5. // POJ 2830 - Max Sequence II
// Model: gpt-6-astra
// Keep the minimum and maximum nonempty suffix products. Store each
// product as a signed normalized mantissa and an integer decimal exponent
// so arbitrarily large products never overflow. O(N) time, O(1) space.
// The discussion clarifies that rounding 9.9995 upward carries into the
// exponent; omit E0 after this normalization, including for values below 1.
#include <cstdio>
#include <cmath>
struct Number {
    int sign, exponent;
    long double mantissa;
    Number(long double x = 0): sign(x > 0 ? 1 : x < 0 ? -1 : 0),
        exponent(0), mantissa(x < 0 ? -x : x) { normalize(); }
    void normalize() {
        if (!sign) { mantissa = 0; exponent = 0; return; }
        while (mantissa >= 10) { mantissa /= 10; ++exponent; }
        while (mantissa < 1) { mantissa *= 10; --exponent; }
    }
};
Number multiply(Number a, const Number &b) {
    a.sign *= b.sign;
    a.mantissa *= b.mantissa;
    a.exponent += b.exponent;
    a.normalize();
    return a;
}
bool lessThan(const Number &a, const Number &b) {
    if (a.sign != b.sign) return a.sign < b.sign;
    if (!a.sign) return false;
    if (a.exponent != b.exponent)
        return a.sign > 0 ? a.exponent < b.exponent : a.exponent > b.exponent;
    return a.sign > 0 ? a.mantissa < b.mantissa : a.mantissa > b.mantissa;
}
void print(Number a) {
    if (!a.sign) { std::puts("0.000"); return; }
    int rounded = (int)std::floor(a.mantissa * 1000 + 0.5L + 1e-9L);
    if (rounded == 10000) { rounded = 1000; ++a.exponent; }
    if (a.sign < 0) std::putchar('-');
    std::printf("%d.%03d", rounded / 1000, rounded % 1000);
    if (a.exponent) std::printf("E%d", a.exponent);
    std::putchar('\n');
}
int main() {
    int n;
    while (std::scanf("%d", &n) == 1) {
        Number low, high, best;
        for (int i = 0; i < n; ++i) {
            double raw;
            if (std::scanf("%lf", &raw) != 1) return 0;
            Number x(raw), lo = x, hi = x;
            if (i) {
                Number a = multiply(low, x), b = multiply(high, x);
                if (lessThan(a, lo)) lo = a;
                if (lessThan(b, lo)) lo = b;
                if (lessThan(hi, a)) hi = a;
                if (lessThan(hi, b)) hi = b;
            }
            low = lo; high = hi;
            if (!i || lessThan(best, high)) best = high;
        }
        print(best);
    }
    return 0;
}
