# 2427 — Smith's Problem

The special-judge gate was explicitly lifted for the 2026-10-18 gpt-6-astra run. The previous record was a gate-only hold with zero submissions. Two real submissions were made; both received Wrong Answer. The evidence suggests a broken judge, rather than an unresolved mathematical approach.

The input consists of positive N up to 100000000, read to EOF. Output positive X,Y satisfying X^2-NY^2=1, both strictly below 10^1000, or `No solution!`. Squares have no positive solution. A nonsquare can also have no permitted solution because its fundamental solution is too large. The discussion gives N=27237237 as an explicit example: http://poj.org/showmessage?message_id=21457 and http://poj.org/showmessage?message_id=21459. This was independently checked with arbitrary-precision arithmetic.

The original solution generates the continued fraction of sqrt(N). Start s=floor(sqrt(N)), m=0, d=1, a=s; numerator predecessors 0,1 and denominator predecessors 1,0. At index k, compute p=a*p_previous+p_previous_previous and q likewise, then m=d*a-m and d=(N-m*m)/d. The residual p^2-Nq^2 equals (-1)^(k+1)*d, so d=1 at odd k identifies the least positive Pell solution. Otherwise set a=(s+m)/d and continue. Stop with no solution if p reaches 10^1000; increasing convergent numerators and the Pell convergent theorem prove there can be no smaller later solution. Arithmetic used base-10000 limbs and only multiplication by a small coefficient and addition. All small integer intermediates fit signed 32-bit under the stated N bound. Exactly 250 base-10000 limbs are allowed; 251 limbs meet or exceed the strict bound.

The independent control builds the entire period through its final coefficient 2*s, evaluates the preceding coefficients backwards from p=1,q=0 using (p,q)=(a*p+q,p), and returns p,q for an even period. For an odd period the norm is -1, so it returns X=2*p*p+1,Y=2*p*q. It uses separate base-10 arithmetic, including schoolbook multiplication, and checks the same digit limit. This construction adapts the author-published Java solution at https://blog.nowcoder.net/n/3feb4c56326d4c55aa5b9c35ca9daab3, adding the statement's size bound absent from that publication. It is a control based on a canonical published method, not a claim that this exact adapted source previously received Accepted.

Both sources compiled with C++98, pedantic warnings, and optimization. The original matched the sample byte-for-byte and passed exact equation, positivity, and length checks for all N from 1 through 10000, the upper boundary and its neighbor, the discussion's oversized case, and 300 deterministic random values through 100000000: 10303 cases total.
