## Statement and complete-domain verification

Read positive integers n <= 1000 until EOF. Print a permutation of 1..n whose absolute position displacements are exactly 0..n-1, or print 0 if none exists. Multiple witnesses are explicitly permitted. There is no leading test count. The sample is input `1 / 2 / 4`, output `1 / 0 / 3 2 4 1` (slashes denote newlines).

For any permutation, the signed displacements sum to zero, so their absolute sum is even. Thus n(n-1)/2 must be even: precisely n mod 4 in {0,1}. The construction below supplies every such case, proving necessity and sufficiency.

Let k=floor(n/4), and use zero-based labels. Alternately take the smallest and largest remaining labels, skipping k before taking a low label. Use these labels as a directed cycle, fixing the omitted label k. Assign each cycle successor the preceding label, then add one for output. The low-label skip must happen before its high-label partner is taken; merely deleting k from an already-interleaved list is wrong (n=5 exposes this). The nonclosing differences run through 1..n-1 except one, and the closing edge to zero provides that missing difference. Handle n=1 with its single fixed point.

The annotated source was built using C++98, pedantic warnings, and optimization. Its sample matched exactly. Every n from 1 through 1000 was run and the actual emitted artifact was checked: correct length, sorted values equal to 1..n, and sorted absolute displacements equal to 0..n-1. Every zero answer was independently certified impossible by the odd absolute-sum parity. Brute enumeration of all permutations through n=9 independently agreed on existence. Removing the skip in a mutant was detected by the official sample.

The valuable regression input is `5`, for which this construction emits `4 2 5 3 1`; its absolute displacements are `3 0 2 1 4`. Preserve it and the statement sample if a future retry is Accepted.

For each i with i+d<=n, try assigning position i the value i+d if both are unused, then try the reverse assignment if distinct. Undo on failure; recurse until d<0. ## Submitted construction

```cpp
// POJ 2825 - Perfect Permutation
// Model: gpt-6-astra
// The sum of all absolute displacements must be even, so n is 0 or 1 mod 4.
// Alternately take the smallest and largest remaining labels, skipping
// k=floor(n/4) on the low side before pairing. Make this a cycle and fix k.
// The consecutive differences contain
// 1..n-1 except the final label, which the closing edge to zero supplies.
// Any valid witness is allowed; cases are read until EOF.
#include <cstdio>
#include <vector>
using namespace std;
int main() {
    int n;
    while (scanf("%d", &n) == 1) {
        if (n % 4 == 2 || n % 4 == 3) {
            puts("0");
            continue;
        }
        int k = n / 4;
        vector<int> cycle, a(n);
        int l = 0, r = n - 1;
        while (l <= r) {
            if (l == k) ++l;
            if (l <= r) cycle.push_back(l++);
            if (l <= r) cycle.push_back(r--);
        }
        a[k] = k;
        int sz = (int)cycle.size();
        for (int i = 0; i < sz; ++i)
            a[cycle[(i + 1) % sz]] = cycle[i];
        for (int i = 0; i < n; ++i)
            printf("%d%c", a[i] + 1, i + 1 == n ? '\n' : ' ');
    }
    return 0;
}
```
