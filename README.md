POJ Solutions
=============

Here are my solutions of [POJ](http://poj.org). My POJ id is [150014](http://poj.org/userstatus?user_id=150014).

Some of these codes are very old and might not work with the new compilers they use now, but they should be easy to fix.

Accepted submissions live under `solutions/<id>/`; write-ups for problems that were tried but not accepted live under `attempts/`.

**Two eras.** Everything committed before 2026 — 758 problems, all from 2014 — I solved myself. Everything from 2026 onward is a coding-agent experiment: Claude Code or Codex reads the statement, writes and tests the solution, submits it through the browser, and iterates on the verdict. `AGENTS.md` is the shared contract, and `TODO` is the backlog they work through. Check the commit date if you want to know which era a solution came from.

Feel free to clone/fork this repo. But **DO NOT USE IT TO CHEAT YOUR HOMEWORK!**
